# Roadmap Marie-Solange V2/V3

## V1 actuelle

- Conversation locale.
- Saisie libre.
- Classification déterministe.
- Préqualification en session.
- Recommandation solution/plan prudente.
- Résumé copiable et message WhatsApp préparé.
- Aucune persistance serveur.

## V2 possible

- Meilleure classification locale.
- Synonymes enrichis par secteur.
- Suggestions plus contextuelles.
- Recherche plus fine dans la base de connaissances.
- Meilleure détection des corrections utilisateur.

## V3 possible

- Centre d'administration.
- Questions inconnues candidates.
- Objections fréquentes.
- Versionnement de la connaissance.
- Publication après validation humaine.
- Historique et audit.
- Rollback d'une version publiée.

La V3 ne doit jamais apprendre automatiquement sans contrôle humain.
